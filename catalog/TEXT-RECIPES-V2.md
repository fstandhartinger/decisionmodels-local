# Runnable text recipes, revision 2

These recipes cover all 11 existing variants of the eight assigned models. Each recipe is **unverified**: no weights, GPU execution, third-party imports, inference, or serving installation occurred during this work. Metadata resolution, source review, wrapper syntax checks and dry-run command expansion are evidence of recipe construction, not evidence of successful inference or benchmark parity. Prior omissions in `RECIPES-NOTES.md` for these models are superseded by this document.

The installer downloads original model files at the existing catalog revisions and verifies their SHA-256 values. Author checkouts are immutable GitHub revisions with hashes of their actual codeload archives. Inline support files are our transport/launch adaptations, individually hashed, written by the runtime extension, and invoked through `{python}` and `{support_dir}`. Code placeholders use the established `{code:code/author}` form. Backends explicitly bind loopback. Installer-managed serving remains HF/Transformers offline and receives no HF token.

## Dependency evidence

Direct package pins came from author project/lockfiles, BH setup scripts, or official [PyPI JSON metadata](https://pypi.org/pypi/fastapi/0.136.3/json) and official PyTorch/vLLM indexes. Newly selected ancillary versions were verified as published packages, not inferred from names. Examples: FastAPI 0.136.3, Uvicorn 0.54.0, HTTPX 0.28.1, Jinja2 3.1.6, flash-linear-attention 0.5.2, NumPy 2.5.3 and SciPy 1.18.1. Bobcat uses NumPy 2.3.5 from Decisio's lock, compatible with vLLM's requirements. Venv recipes pin direct packages; except Decisio they do not freeze every transitive/build dependency.

`uv pip compile --python-version 3.12 --python-platform x86_64-manylinux_2_39 --only-binary :all:` resolved Quyet, Deck31B, Rene, Bobcat, Decider and Torchcast GPU stacks without executing package builds. CPU Decider resolved 47 packages. Cross-resolution with `MACOSX_DEPLOYMENT_TARGET=14.0`, `--python-platform aarch64-apple-darwin` resolved Quyet MPS (36 packages) and Decider MPS (47 packages). The initial macOS 13 target correctly refused the Torch wheel; macOS 14 is now documented. The initial generic Linux target refused a vLLM transitive llguidance wheel; the modern glibc target resolved it. These checks do not establish a minimum Linux glibc for every recipe or runtime kernel compatibility. Rune's wheel install and Decisio's frozen environment installation were not executed.
